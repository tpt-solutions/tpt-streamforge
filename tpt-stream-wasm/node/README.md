# tpt-streamforge-node

In-memory streaming ETL for Node.js, backed by the tpt-streamforge WASM engine.

```js
const { Pipeline } = require('tpt-streamforge-node');

const p = new Pipeline('id,name,amount\n1,alice,10\n2,bob,20\n')
  .filter('amount > 10')
  .sort(['amount'], true)
  .aggregate(['name'], ['count_all'], ['']);

console.log(p.toJSON());
// [{ name: 'bob', count_all: 1 }]
```

## API

```js
const { Pipeline, createPipeline, readCSV } = require('tpt-streamforge-node');
```

- `new Pipeline(csv, chunkRows?)` / `Pipeline.fromCsv(csv, chunkRows?)` — build a
  pipeline from CSV text.
- `Pipeline.readFile(path, chunkRows?)` — read a CSV file from disk.
- Fluent transforms (each mutates and returns `this`):
  - `filter(expr)` — keep rows where the [expression] evaluates to true.
  - `map(columns, exprs)` — replace the schema; row gets `columns[i] = exprs[i]`.
  - `sort(columns, descending=false)` — stable sort.
  - `dedup(columns)` — keep the first row per key.
  - `aggregate(groupBy, fns, columns)` — fns ∈ {sum, avg, count, count_all, min, max}.
- Results: `toCSV()`, `toJSON()`, `numRows()`, `columnNames()`, `writeFile(path)`,
  `execute()` → `{ rows, csv }`.
- Telemetry: `onProgress(callback)` / `clearProgress()`. The callback fires
  once per batch for `filter`/`map`/`dedup` and once at completion of every
  operation (`from_csv`, `sort`, `aggregate`, `toCSV`, `toJSON`) with
  `{ op, done, total, rowsIn, rowsOut, elapsedMs }`:

  ```js
  const events = [];
  new Pipeline(csv, 1000).onProgress((e) => events.push(e)).filter('amount > 0');
  // e.g. { op: 'filter', done: 2, total: 2, rowsIn: 2000, rowsOut: 1234, elapsedMs: 3.1 }
  ```

  Errors thrown by the callback are reported via `console.error` and never
  abort the operation.

## Building from source

Requires [wasm-pack] (Node 18+ to run tests):

```sh
cd tpt-stream-wasm
wasm-pack build --target nodejs --out-dir node/pkg
cd node
npm test
```

The `pkg/` folder is regenerated by `npm run build` in `node/` (and is
git-ignored, so fresh checkouts must build before testing or publishing).
